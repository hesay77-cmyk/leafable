# Leafable

Leafable 是 Windows 10 / 11 上免费的 PDF 软件，界面和操作照 Mac「预览」：看 PDF，合并、排序、删页、旋转、拆分、压缩，转图片、Word、Excel；高亮、签名、填表、加密码、涂黑；扫描件也能认出文字。没有广告，不用注册，文件只在你的电脑上处理。
